# 📋 発注台帳ビューアー

野菜の発注データを効率的に管理するためのWebアプリケーションです。Excelファイルからデータを読み込み、可視化、編集、集計が可能です。

## ✨ 主な機能

### 📊 データ管理
- **Excelファイル読込**: ドラッグ&ドロップまたはファイル選択で複数のExcelファイルを読み込み
- **IndexedDB保存**: ブラウザのローカルストレージにデータを保存・読み込み
- **複数ファイル対応**: 複数のExcelファイルを同時に読み込んで統合表示

### 🔍 フィルタ・検索機能
- **店舗フィルタ**: 複数店舗から表示対象を選択
- **仕入先フィルタ**: 仕入先別にデータをフィルタリング
- **期間スライダー**: 日付範囲を直感的に選択
- **品目検索**: 品目名で素早く検索
- **ファイルフィルタ**: 読み込んだファイル単位で表示切替

### 🏷️ タグ機能
- **3階層タグ**: 大分類・中分類・小分類の3階層でタグ付け
- **タグインポート**: Excel/CSVからタグ情報を一括インポート
- **タグテンプレート出力**: 現在の品目リストからタグ設定用テンプレートを生成
- **タグ別集計**: タグごとに数量・原価・売価・値入率を階層表示

### 📈 集計・分析
- **リアルタイム集計**: 原価計・売価計・値入率を自動計算
- **期間別集計**: 日付ごとの数量を一覧表示
- **交点集計**: 行（品目）と列（日付）を選択して集計
- **インタラクティブツールチップ**: マウスホバーで詳細情報を表示

### ✏️ 編集機能
- **セル直接編集**: テーブル上で数量を直接編集（単一店舗選択時のみ）
- **商品追加**: 新規商品をフォームから追加
- **商品削除**: 不要な商品を削除
- **タグ編集**: テーブル上でタグを直接編集

### 📤 エクスポート機能
- **Excel出力**: 現在の表示状態をExcelファイルとして出力
- **CSV出力**: CSVフォーマットでデータをエクスポート
- **タグ別集計出力**: タグごとの集計結果をExcelで出力
- **印刷**: ブラウザの印刷機能で帳票出力

### 🎨 表示カスタマイズ
- **列表示切替**: 原価・売価・入数・各タグ列の表示/非表示
- **ゼロ表示**: 数量0の品目の表示/非表示
- **並び替え**: 品目名順・タグ順・数量順でソート
- **カラム幅調整**: テーブルの列幅をマウスでリサイズ
- **全画面モード**: フルスクリーンで作業可能

## 🚀 使い方

### 1. アプリケーションの起動

#### 🌐 オンラインで使用（推奨）

このアプリケーションは GitHub Pages でホスティングされています。

**アクセス方法:**
```
https://watanabe-masao.github.io/Tool3/
```

ブラウザでアクセスするだけで、すぐに使用開始できます！

#### GitHub Pages でデプロイする方法

1. **リポジトリ設定**
   - GitHub リポジトリページを開く
   - `Settings` → `Pages` に移動
   - `Source` で使用するブランチを選択（例: `claude/setup-indexeddb-011pS5ZxjpRthVNAAZrqjJFK`）
   - `Root` ディレクトリを選択
   - `Save` をクリック

2. **デプロイ完了を待つ**
   - 数分後に `https://[ユーザー名].github.io/[リポジトリ名]/` でアクセス可能になります
   - デプロイ状況は `Actions` タブで確認できます

3. **動作確認**
   - デプロイされたURLにアクセス
   - Excelファイルをドラッグ&ドロップしてテスト

#### 💻 ローカル環境で実行

開発やテストの場合はローカルサーバーで実行できます。

```bash
# Pythonの簡易サーバーを使用（Python 3の場合）
python3 -m http.server 8000

# ブラウザで開く
# http://localhost:8000
```

または、任意のWebサーバーでホスティングしてください。

### 2. Excelファイルの読み込み

1. **ドラッグ&ドロップ**: Excelファイルをドロップゾーンにドラッグ
2. **ファイル選択**: ドロップゾーンをクリックしてファイル選択ダイアログから選択
3. 読み込み完了後、自動的にデータが表示されます

#### Excelファイルのフォーマット要件
- 7行目（インデックス6）: ヘッダー行（店舗コードが6列目以降に配置）
- 8行目以降: データ行
  - 0列目: 品目情報
  - 2列目: 日付（M/D形式）
  - 3列目: 原価/売価（例: "100/150"）
  - 4列目: 入数
  - 6列目以降: 各店舗の数量

### 3. データの操作

#### フィルタリング
- **店舗**: 「🏪 店舗」ボタンから店舗を選択
- **仕入先**: 「🚚 仕入先」ボタンから仕入先を選択
- **期間**: スライダーで日付範囲を調整
- **品目検索**: 検索ボックスに品目名を入力

#### タグ付け
1. テーブルのタグ列に直接入力
2. または、Excelからタグ情報をインポート
   - 「📥 インポート」ボタンからExcel/CSVを選択
   - フォーマット: 品目名、大分類、中分類、小分類の列を含む

#### 数量の編集（単一店舗選択時のみ）
1. 編集したいセルをクリック
2. 数量を入力してEnterキーまたは外側をクリック

#### 商品の追加
1. 「➕ 商品を追加」ボタンをクリック
2. 品目名、原価、売価、タグなどを入力
3. 「追加」ボタンをクリック

### 4. データの保存・読み込み

#### 保存
1. 「💾 保存」ボタンをクリック
2. 保存名を入力して保存

#### 読み込み
1. 画面上部の「💾 保存データ」セクションを展開
2. 読み込みたいデータをクリック

### 5. エクスポート

- **📊 Excel出力**: 現在のフィルタ・表示設定でExcel形式で出力
- **📄 CSV出力**: CSV形式で出力
- **🖨️ 印刷**: ブラウザの印刷機能で印刷
- **タグ別集計出力**: タグ統計セクションの「📊 集計出力」ボタン

## ☁️ Firebase クラウド同期の設定

このアプリケーションは Firebase を使用して、PC とスマートフォン間でデータを同期できます。

### 環境変数の設定

Firebase の設定は環境変数で管理されています。

1. **.env ファイルの作成**
   ```bash
   cp .env.example .env
   ```

2. **.env ファイルを編集**

   以下の項目を自分の Firebase プロジェクトの設定値に置き換えてください：
   ```
   FIREBASE_API_KEY=your_api_key_here
   FIREBASE_AUTH_DOMAIN=your_project_id.firebaseapp.com
   FIREBASE_PROJECT_ID=your_project_id
   FIREBASE_STORAGE_BUCKET=your_project_id.firebasestorage.app
   FIREBASE_MESSAGING_SENDER_ID=your_messaging_sender_id
   FIREBASE_APP_ID=your_app_id
   ```

3. **ビルド**
   ```bash
   npm run build
   ```

   ビルド時に自動的に `.env` ファイルから設定を読み込み、`src/env-config.ts` が生成されます。

### Firebase プロジェクトの設定方法

1. **プロジェクト作成**
   - [Firebase Console](https://console.firebase.google.com/) にアクセス
   - 「プロジェクトを追加」をクリック
   - プロジェクト名を入力して作成

2. **ウェブアプリの追加**
   - プロジェクト設定 → 「ウェブアプリを追加」
   - アプリのニックネームを入力
   - 表示される Firebase 設定値を `.env` ファイルにコピー

3. **Firestore Database の有効化**
   - 左メニューから「Firestore Database」を選択
   - 「データベースを作成」をクリック
   - 「本番環境モード」を選択（後でルールを設定）
   - ロケーションを選択（asia-northeast1 推奨）

4. **🔒 セキュリティルールの設定（重要）**
   - Firestore Database → 「ルール」タブ
   - `firestore.rules` ファイルの内容をコピー＆ペースト
   - 「公開」ボタンをクリック

   ```javascript
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /rooms/{roomCode} {
         allow read: if request.auth != null
                     && roomCode.matches('^[A-Z0-9]{6}$');
         allow write: if request.auth != null
                      && roomCode.matches('^[A-Z0-9]{6}$')
                      && request.resource.size() < 5000000;
         allow delete: if request.auth != null;
       }
       match /{document=**} {
         allow read, write: if false;
       }
     }
   }
   ```

5. **Authentication の設定**
   - 左メニューから「Authentication」を選択
   - 「始める」をクリック
   - 「Sign-in method」タブ → 「匿名」を有効化

6. **動作確認**
   - アプリケーションで「☁️ 同期」ボタンをクリック
   - 自動的に Firebase に接続されることを確認

### 使い方

1. アプリケーションで「☁️ 同期」ボタンをクリック
2. 「➕ 新規ルーム作成」で6桁のルームコードを生成
3. 他のデバイスで同じルームコードを入力して「🔗 ルームに参加」
4. 「⬆️ アップロード」でデータをクラウドに保存
5. 「⬇️ ダウンロード」で他のデバイスからデータを取得
6. 「🔄 自動同期」でリアルタイム同期を有効化

## ⚠️ 注意事項

1. **データはブラウザに保存されます**
   - IndexedDBを使用しているため、ブラウザのデータを消去すると保存データも削除されます
   - 定期的にExcel/CSV形式でバックアップを取ることを推奨します

2. **セル編集は単一店舗選択時のみ**
   - 複数店舗を選択している場合、データの整合性のためセル編集は無効になります

3. **Excelファイルフォーマット**
   - アプリケーションは特定のExcelフォーマットを想定しています
   - フォーマットが異なる場合、正しく読み込めない可能性があります

4. **GitHub Pages でのホスティング**
   - 完全に静的なアプリケーションのため、サーバーサイド処理は不要です
   - IndexedDB はブラウザ単位で保存されるため、異なるブラウザ間でデータは共有されません
   - HTTPS 接続が推奨されます（GitHub Pages は自動的に HTTPS を提供）

5. **🔒 Firebase セキュリティ**
   - **必ず Firestore Security Rules を設定してください**
   - ルール未設定の場合、誰でもデータにアクセス可能な状態になります
   - `firestore.rules` ファイルを Firebase Console でデプロイすることを強く推奨
   - 6桁のルームコードのみが有効で、認証済みユーザーのみアクセス可能

6. **📡 オフライン対応**
   - Firestore のオフライン永続化機能が有効化されています
   - ネットワーク接続が不安定でも、ローカルキャッシュからデータを読み込めます
   - 再接続時に自動的にクラウドと同期されます
   - 複数タブを開いている場合は機能が制限される場合があります

## 🔧 開発・カスタマイズ

### 開発環境のセットアップ

1. **依存関係のインストール**
   ```bash
   npm install
   ```

2. **環境変数の設定**
   ```bash
   cp .env.example .env
   # .envファイルを編集してFirebase設定を追加
   ```

3. **ビルド**
   ```bash
   npm run build
   ```

4. **開発時の自動ビルド**
   ```bash
   npm run watch
   ```

### データベース設定の変更
`src/app.ts` の以下の定数を変更:
```typescript
const DB_NAME = 'VegetableOrderDB';  // データベース名
const DB_VERSION = 3;                 // バージョン
const STORE_NAME = 'savedData';       // オブジェクトストア名
```

### Firebase設定の変更
`.env` ファイルを編集して、ビルドしてください:
```bash
npm run build
```

`css/style.css` で色やレイアウトを自由に変更できます。
